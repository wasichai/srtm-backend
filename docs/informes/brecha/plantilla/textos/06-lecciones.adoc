== Lecciones y consideraciones

* La brecha es una estimación del motor con los datos de cada sistema, no una deuda determinada: cada caso se
  verifica antes de una fiscalización.
* La confianza depende de la calidad del levantamiento; un predio «dudoso» no es un error de rentas, sino un
  dato que todavía no se puede usar.
* Las cifras cambian con cada corte: se citan siempre con su fecha de corte ({fecha-corte}).
